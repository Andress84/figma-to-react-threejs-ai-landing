# AI SaaS Landing Page

Original AI SaaS landing page designed and developed as a modern frontend portfolio showcase.

## Stack

- React
- TypeScript
- Vite
- Three.js
- React Three Fiber
- Drei
- GSAP
- Modern CSS

## Project Goals

- Reproduce the original Figma design across desktop, tablet, and mobile
- Build a clean component-based React architecture
- Add performant WebGL visual effects with Three.js
- Add polished motion and micro-interactions
- Maintain accessibility and responsive behavior
- Deploy the final implementation to GitHub Pages
